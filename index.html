06 / Developers

One key. One balance. Pay for inference in scrip.

A REST API metered in scrip. Each call debits your onchain balance and returns exactly what it cost, so usage always reconciles against the ledger. No invoices, no surprises.

Manage API keys
request.shExample
$ curl -X POST $SCRIP_API/v1/chat \
  -H "x-scrip-key: $SCRIP_KEY" \
  -H "Idempotency-Key: req_7f3a91c2" \
  -d '{"model":"default",
     "messages":[{"role":"user","content":"hello"}]}'
